{% comment %} Context menu panel ================== The floating shell every right-click menu is built on: fixed positioning at the cursor, the base-100 card look, click-outside and Escape dismissal. The rows themselves are module business, so the caller supplies them as a template path rendered inside the panel - including the `
    ` wrapper, since some menus hold several (one per node type). Rows should be built with `ui/partials/context_menu_item.html`. Params (Alpine expression fragments evaluated in the caller's scope, except `items`, `width` and `id` which are Django values): - items: template path holding the menu's rows - open: expression driving x-show (e.g. "ctxMenu.open") - close: expression run on Escape / outside (e.g. "ctxMenu.open = false") - x, y: expressions for the cursor position (e.g. "ctxMenu.x") - width: optional - Tailwind width class (default "w-56") - id: optional - DOM id - x_data: optional - component to instantiate on the panel itself {% endcomment %}
