{% comment %} Drawer Item Component ===================== A reusable component for drawer/sidebar menu items. Parameters: ----------- - href: URL for the link (optional if disabled; if omitted, renders a button) - icon: Lucide icon name (e.g., "folder", "clock", "trash-2") - icon_expr, icon_true, icon_false: two-state icon. icon_expr is an Alpine expression; the icon_true icon is shown while it is truthy, icon_false otherwise. Both icons are rendered statically and toggled with x-show because a reactive :data-lucide binding cannot work: Lucide draws the SVG once at hydration and never re-renders when the attribute changes. - icon_initial: Boolean, the value icon_expr has when the page renders, so only the matching icon is in the HTML's visible state - without it both icons show side by side until Alpine binds. - label: Text label for the item - color: Optional DaisyUI color token (e.g., "primary", "warning", "error"). Controls icon tint when inactive and highlight when active. Defaults to "primary" behaviour when omitted. - active: Boolean, whether this item is currently active (default: False) - active_binding: Optional Alpine.js expression to control active state - disabled: Boolean, whether this item is disabled (default: False) - badge: Optional badge text (e.g., "Soon", "3", "New") - badge_binding: Alpine expression for a badge whose text changes (e.g. a countdown or a live count). Ignored when `badge` is given, since a static badge and a reactive one on the same row would fight over the slot. - badge_type: Badge variant (default: "sm") - can be "xs", "sm", "md", "lg" - x_target: Optional Alpine.js x-target attribute - x_target_history: Optional x-target history mode ("push" or "replace") - onclick: Optional JavaScript onclick handler - tooltip: Optional tooltip text for collapsed state - title_binding: Optional Alpine.js expression for the title attribute - collapse_expr: Optional Alpine.js expression for the effective collapse state (default: "collapsed"). Pass e.g. "sidebarCollapsed()" for modules that decouple mobile layout from the stored desktop preference. - collapsed_initial: Boolean, the collapsed state the server knows when it renders the page (the module's stored preference). Alpine binds only after the parse, so without it the item paints expanded, label and all, and snaps to the rail a few frames later. - mobile_rail: Boolean, the drawer is the 64px icon rail below `lg` whatever the preference says (a `drawer-open` shell, not `lg:drawer-open`). Adds the `max-lg:` variants of the collapsed classes so the first paint on a phone is the rail too. Both are usually set once, in a {% with %} around the whole
: an {% include %} inherits them from the enclosing context. Every collapsed-state binding below is the object form, so Alpine drops the static class on mount. - aria_label: Optional static aria-label text - aria_label_binding: Optional Alpine.js expression for aria-label Usage Examples: --------------- {% include "ui/partials/drawer_item.html" with href="/files" icon="folder" label="My Files" active=True color="primary" %} {% include "ui/partials/drawer_item.html" with icon="clock" label="Recent" disabled=True badge="Soon" %} {% include "ui/partials/drawer_item.html" with href="/trash" icon="trash-2" label="Trash" color="error" badge="5" badge_type="error" %} {% endcomment %} {% with c=color|default:"primary" %}
