{% comment %} Gantt Chart =========== Renders the geometry produced by workspace.common.charts.gantt_chart as an inline SVG with a real pixel width: the caller wraps it in an overflow-x-auto container so long spans scroll instead of shrinking. Parameters: ----------- - chart: the dict returned by gantt_chart() - aria_label: accessible description of what the chart shows Activating a row (click or Enter) dispatches a bubbling `gantt-row` event whose detail carries `{ id }`; the caller listens for it and decides what opening a row means. The partial itself never names a module. Every coordinate in `chart` is a pre-formatted string and the template does no arithmetic on purpose - see the docstring in charts.py. {% endcomment %}
