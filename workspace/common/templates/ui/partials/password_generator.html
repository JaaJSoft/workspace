{% comment %} Password and passphrase generator, for any form that needs a strong value. Parameters: - deps_expr: Alpine expression giving the generator its dependencies, chiefly { randomBytes } (default "{}", meaning the browser's own CSPRNG). A caller holding an audited CSPRNG wrapper passes it here so its randomness stays inside the code it audits. - show_apply: truthy to render the "Use" button, for a host with a field to write into. A standalone generator leaves it out and keeps Copy only. The panel owns no clipboard and no field. It dispatches two events and lets the host decide what they mean: - password-apply, detail { value } - put this in the field - password-copy, detail { value } - copy this, with whatever clearing policy the host applies Both hosts mount it under x-if, so closing the panel tears the component down and destroy() drops the value it was holding. {% endcomment %}
{% comment %} Shown in the clear, next to a field that masks it. Deliberate: a value nobody can read is a value nobody can check, and every generator does the same. Runs of one character kind are coloured so a digit is not mistaken for a letter when reading it back. {% endcomment %}
