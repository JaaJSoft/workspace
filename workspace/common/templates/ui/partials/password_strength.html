{% load static %} {% comment %} Password strength meter: a bar and a short verdict under a field where the user is choosing a password, updated as they type. Backed by passwordStrengthMeter() in ui/js/password_strength.js, which the host page loads; the estimator itself is fetched on demand. Parameters: - password_expr: Alpine expression giving the password being typed (required). Read from the host's scope, so the meter can sit anywhere under the component that owns the field. - visible_expr: Alpine expression, truthy when the field is on screen (default "true"). The estimator is fetched as soon as it is, before the first keystroke needs it; a host that renders the field behind a tab passes the tab condition so the page does not pay for it on first paint. Advisory only: nothing here blocks a submission. The host keeps its own floor, if it has one, and the server's validators stay the gate. {% endcomment %}
