{% comment %} Size slider =========== A small range between a small and a large grid icon, for the tile size of a grid view. The scale runs from 1 to 5; what each step measures is the caller's business. Params: - model: Alpine expression x-model.number binds, updated while the thumb moves - change: Alpine expression run once the thumb is released, to save the value - initial_value: optional - the step the page was rendered with, so the thumb sits there before Alpine binds - full_width: optional - stretch the range over the width the slider is given (a popover) instead of its compact toolbar size {% endcomment %}
