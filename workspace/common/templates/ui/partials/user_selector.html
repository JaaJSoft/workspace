{% comment %} Reusable user selector component with search-as-you-type. Features: real avatars, keyboard navigation (arrows + enter), hover highlight. Parameters: - placeholder: Placeholder text for the search input (default: "Search users...") - on_select_event: Custom event name dispatched when a user is selected (required) - local_source: Optional Alpine expression (evaluated in the parent scope) returning a list of {id, username, first_name, last_name}. When set, the component filters that list client-side instead of querying the search API, and the dropdown opens on focus with the full list. Usage: {% include "ui/partials/user_selector.html" with on_select_event="user-selected" placeholder="Add a user..." %} {% include "ui/partials/user_selector.html" with on_select_event="assignee-selected" local_source="unassignedUsers()" %} The dispatched event contains { detail: { user: { id, username, first_name, last_name } } } {% endcomment %}
