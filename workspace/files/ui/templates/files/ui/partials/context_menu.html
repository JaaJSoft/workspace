{% comment %} Rows of the file browser context menu. The panel around them is `ui/partials/context_menu_panel.html`, included from index.html, and it is what carries the `contextMenu()` component (see files/ui/js/context_menu.js). The node menu is driven entirely by `POST /api/v1/files/actions`: the registry decides which actions exist and whether they're available, so nothing here may hard-code a row. The background menu (right-click on empty space) targets the current folder rather than a node, so it has no registry entry and is written out below. {% endcomment %}
