--- hard-drive | {% translate "WebDAV Access" %}

{% translate "Mount your files as a network drive using WebDAV. Your WebDAV URL is:" %}

https://<{% translate "your-domain" %}>/dav/

{% blocktranslate trimmed %} Sign in with your username and password. If your account uses single sign-on, create an API token in Settings > API Tokens and enter it as the password. {% endblocktranslate %}

Windows

  1. {% blocktranslate trimmed %} Open File Explorer and click Map network drive. {% endblocktranslate %}
  2. {% translate "Enter the WebDAV URL as the folder path." %}
  3. {% blocktranslate trimmed %} Check Connect using different credentials and enter your username and password. {% endblocktranslate %}
  4. {% translate "If connecting over HTTP, add a registry key to allow Basic auth:" %} HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters\BasicAuthLevel = 2 {% blocktranslate trimmed %} then restart the WebClient service. {% endblocktranslate %}

macOS

  1. {% blocktranslate trimmed %} In Finder, press Cmd + K. {% endblocktranslate %}
  2. {% blocktranslate trimmed %} Enter the WebDAV URL and click Connect. {% endblocktranslate %}
  3. {% translate "Enter your credentials when prompted." %}

Linux

  1. {% blocktranslate trimmed %} Install davfs2: sudo apt install davfs2 {% endblocktranslate %}
  2. {% blocktranslate trimmed %} Mount via command line or add to /etc/fstab. {% endblocktranslate %}
  3. {% blocktranslate trimmed %} Alternatively, use GNOME Files > Other Locations > Connect to Server. {% endblocktranslate %}

iOS / Android

{% blocktranslate trimmed %} Use a WebDAV-compatible app such as FE File Explorer, Solid Explorer, or Documents by Readdle. {% endblocktranslate %}
