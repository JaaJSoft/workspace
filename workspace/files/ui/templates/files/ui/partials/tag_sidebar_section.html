{% comment %} Tags sidebar section ==================== Favourite tags, rendered client-side from the tags mixin's `allTags`, and an "All tags" row that opens the tag manager dialog. Shared by the Files and Notes sidebars; the consuming component must spread `tagsMixin()` and provide `tagViewHref(tag)`, `openTagView(tag)` and `isTagViewActive(tag)`. Parameters: - collapse_expr: Alpine expression for the collapsed state (default "collapsed") - active_class: classes of the active row, written out in full so Tailwind sees them (default: the Files sidebar's primary tint) - heading_class: classes of the section heading (default matches the Files sidebar) {% endcomment %} {% with ce=collapse_expr|default:"collapsed" active=active_class|default:"bg-primary/10 text-primary hover:bg-primary/20" %}
