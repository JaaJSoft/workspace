{% comment %} Tags sidebar section ==================== Favourite tags, rendered client-side from the tags mixin's `allTags`, and a header button that opens the tag manager dialog. Shared by the Files and Notes sidebars; the consuming component must spread `tagsMixin()` and provide `tagViewHref(tag)`, `openTagView(tag)` and `isTagViewActive(tag)`. Parameters: - collapse_expr: Alpine expression for the collapsed state (default "collapsed") - active_class: classes of the active row, written out in full so Tailwind sees them (default: the Files sidebar's module tint) - heading_class: classes of the section heading (default matches the Files sidebar) - collapsed_initial, mobile_rail: the server-known collapsed state and whether the drawer is the icon rail below `lg`, as for ui/partials/drawer_item.html. The header row (heading plus two square buttons) cannot shrink below its content, so it is hidden in the HTML itself while the sidebar is the rail and bound in the object form: `x-show` alone hides it one animation frame after the aside has narrowed, and for that frame it pokes out of the rail. {% endcomment %} {% with ce=collapse_expr|default:"collapsed" active=active_class|default:"bg-module/10 text-module hover:bg-module/20" %}
