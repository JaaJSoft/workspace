--- list | {% translate "Lists" %}

{% translate "Lists gather contacts of one address book: family, clients, a team." %}

  • {% blocktranslate trimmed %} Create a list with the + next to the Lists heading; rename or delete it from its row menu. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Add a contact from its panel with Add to list; deleting a list never deletes its contacts. {% endblocktranslate %}
  • {% translate "The group icon on a row marks a list that belongs to a group's book." %}
--- share-2 | {% translate "Sharing a contact" %}

{% translate "A contact leaves the workspace as a vCard, the format every phone and address book reads." %}

  • {% blocktranslate trimmed %} Export writes a .vcf file: one contact, one list, or a whole address book. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Show QR code puts a single contact on screen; another phone's camera reads it straight into its address book. {% endblocktranslate %}
  • {% blocktranslate trimmed %} Import reads a .vcf back, updating a contact already there rather than duplicating it. {% endblocktranslate %}
