{% load ui_tags %} {% help_items as items %} book-user | Address books | checked

A contact belongs to one address book: My contacts, which only you see, or one of your groups, shared with every member of that group.

  • Pick the book in the sidebar to narrow the list; All shows every contact you can reach.
  • A contact can be moved to another book from its Actions menu.
  • Link a contact to a workspace account to show that account's picture and name.
--- list | Lists

Lists gather contacts of one address book: family, clients, a team.

  • Create a list with the + next to the Lists heading; rename or delete it from its row menu.
  • Add a contact from its panel with Add to list; deleting a list never deletes its contacts.
  • The group icon on a row marks a list that belongs to a group's book.
--- share-2 | Sharing a contact

A contact leaves the workspace as a vCard, the format every phone and address book reads.

  • Export writes a .vcf file: one contact, one list, or a whole address book.
  • Show QR code puts a single contact on screen; another phone's camera reads it straight into its address book.
  • Import reads a .vcf back, updating a contact already there rather than duplicating it.
--- smartphone | Sync with Your Devices

Your address books sync both ways with the contacts app of your phone or computer (CardDAV). The server address is:

{{ request.scheme }}://{{ request.get_host }}/carddav/

Sign in with your username and password. If your account uses single sign-on, create an API token in Settings > API Tokens and enter it as the password.

  • iPhone, iPad, Mac: Add a CardDAV account and enter the server address.
  • Android: Use DAVx⁵ with the server address.
  • Thunderbird: New address book > Add CardDAV address book, then the server address.

My contacts and each of your groups' books appear as separate address books, and lists sync as contact groups.

--- code | API Access
  • Base URL: /api/v1/people
  • Authentication: Use your session cookie or API token.
  • Documentation: Full API docs are available at /schema/swagger-ui/.
