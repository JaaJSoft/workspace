{% comment %} Rows of a photo's context menu. The panel around them is `ui/partials/context_menu_panel.html`, included from index.html. The file actions come from `POST /api/v1/files/actions`, narrowed to the ones that make sense on a photo (see PHOTO_ACTIONS in photos.js), so a row is only ever offered when the registry says the user may do it. Download is a link rather than a button, to carry the download attribute. "Open in Files" is not a file action: it is written out here, as in the notes menu, and so are the album rows, which the album action registry gates instead, the face rows, offered while the user has face grouping on, and Hide, which never touches the file: it only takes it out of the viewer's own library. On the Hidden view the photo is out of albums and faces, so those rows give way to Unhide. A photo of a shared album the viewer cannot open in Files (albumScoped) has no file action and no place in Files: its menu is the viewer, the download the album allows (through the album), and the album rows. {% endcomment %}
