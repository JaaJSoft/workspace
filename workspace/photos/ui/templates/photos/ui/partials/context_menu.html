{% comment %} Rows of a photo's context menu. The panel around them is `ui/partials/context_menu_panel.html`, included from index.html. The file actions come from `POST /api/v1/files/actions`, narrowed to the ones that make sense on a photo (see PHOTO_ACTIONS in photos.js), so a row is only ever offered when the registry says the user may do it. Download is a link rather than a button, to carry the download attribute. "Open in Files" is not a file action: it is written out here, as in the notes menu, and so are the album rows, which the album action registry gates instead, and the face rows, offered while the user has face grouping on. {% endcomment %}
