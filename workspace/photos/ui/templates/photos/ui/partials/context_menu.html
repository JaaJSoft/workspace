{% comment %} Rows of a photo's context menu. The panel around them is `ui/partials/context_menu_panel.html`, included from base.html. ctxMenuRows() in photos.js decides which rows show, in which group: every row is written out here, in that order, and asks it with ctxShows() and ctxRule(). The file actions it offers come from `POST /api/v1/files/actions` (see PHOTO_ACTIONS), so a row is only ever offered when the registry says the user may do it. The album rows follow the album action registry instead, the face rows the user's face grouping, Similar photos the instance's embeddings. Hide never touches the file: it only takes it out of the viewer's own library. Marking it sensitive blurs it for everyone who can open it. A photo of a shared album the viewer cannot open in Files (albumScoped) has no file action and no place in Files: its menu is the viewer, the download the album allows (through the album), and the album rows. {% endcomment %}
