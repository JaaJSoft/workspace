{% comment %} Epic dropdown: single-value selector matching _status_selector.html, since a task belongs to at most one epic. Unlike the status selector the rows are Alpine-rendered from the board's shared reactive `epics` list (resolved through the scope chain), so an epic created in the settings is pickable immediately - no page reload. The menu only offers open epics plus the "No epic" reset; a closed epic still on the task renders struck-through in the trigger so the current value never displays blank. Like the label combobox, admins on a writable project get an inline-create row at the bottom of the menu (reads `role` and `writable` from the Django context); the API enforces admin itself. Creation pushes into the shared list and selects the new epic in one move. Params: - model_expr: Alpine l-value holding the current epic uuid or '' (required), e.g. "data.epic" or "form.epic". - on_change: optional Alpine statement run after the value is set. - disabled: Django flag - render the trigger disabled (permission gating). - label: accessible field name, prepended to the trigger's visible value as screen-reader-only text. {% endcomment %}
