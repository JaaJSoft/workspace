{% comment %} Label combobox: search-as-you-type over the project's labels, with an admin-only "Create ..." row when the query matches no existing label. Params: - on_select_event: Django string - CustomEvent dispatched on window with { detail: { label } } when a label is picked (required) - all_source: Alpine expression returning every project label (required) - selected_source: Alpine expression returning the selected uuid list (required) - placeholder: Django string (default "Add label...") - no_create: Django flag - hide the admin "Create ..." row (pure picker, e.g. the filter bar, where creating a label makes no sense) Reads `role`, `writable` and `project` from the Django context: admins on a writable project get a create URL, everyone else gets a pure picker. The create URL is cosmetic gating only - the labels API enforces admin itself. On creation the component dispatches "project-label-created" with the new label (handled once on the board root), then the selection event. {% endcomment %}
