{% comment %} Milestone dropdown: single-value selector matching _epic_selector.html, since a task belongs to at most one milestone. Rows are Alpine-rendered from the board's shared reactive `milestones` list (resolved through the scope chain), so a milestone created in the settings is pickable immediately - no page reload. The menu only offers open milestones plus the "No milestone" reset; a closed milestone still on the task renders struck-through in the trigger so the current value never displays blank. Unlike the epic selector there is no inline-create row here - a milestone needs a date, so creation stays in the settings page. Params: - model_expr: Alpine l-value holding the current milestone uuid or '' (required), e.g. "data.milestone" or "form.milestone". - on_change: optional Alpine statement run after the value is set. - disabled: Django flag - render the trigger disabled (permission gating). - label: accessible field name, prepended to the trigger's visible value as screen-reader-only text. {% endcomment %}
