{% comment %} Shared board/backlog filter bar. Filtering is server-side: every change re-fetches the current view with the filters as query parameters (see applyFilters in board.js), so a filtered view is shareable by URL. The filter state lives on the root projectBoard component and is re-synced from the URL after each content swap. {% endcomment %}
{% comment %} The dropdowns share a row that scrolls sideways rather than shrinking, so no label gets clipped whatever a project's member/label/status names are. It stays a scroll container at every width: the selects are sized by their widest option, so a long name would otherwise spill out of the bar and scroll the whole page. On mobile the row spans the full width, keeping the bar at two lines. {% endcomment %}
