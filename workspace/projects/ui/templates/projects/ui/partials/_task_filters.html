{% comment %} Shared board/backlog filter bar. Filtering is server-side: every change re-fetches the current view with the filters as query parameters (see applyFilters in board.js), so a filtered view is shareable by URL. The filter state lives on the root projectBoard component and is re-synced from the URL after each content swap. Assignee and label are multi-value (repeated query params, OR'd server-side) and reuse the same picker components as the task form; the active selections render as removable chips on their own row. The pickers sit outside the scrollable select row on purpose: their dropdowns are absolutely positioned and an overflow-x-auto ancestor would clip them. {% endcomment %}
