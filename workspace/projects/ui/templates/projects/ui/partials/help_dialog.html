--- square-kanban | Views
  • Overview — Task counts and recent activity at a glance.
  • Board — Kanban columns for active work. Drag cards between columns or reorder them within one.
  • Backlog — Tasks waiting to be planned, kept off the board until you move them.
  • All tasks — A flat list of every task in the project, grouped by column.
--- list-todo | Tasks
  • Create — Use the New task button on the board or backlog.
  • Details — Click a card to open the task panel: description, status, priority, due date, assignees, labels, comments, and activity.
  • Priorities — Rank tasks Low, Medium, High, or Urgent.
  • References — Every task gets a reference like {{ project.key }}-42. Mention it in a description or comment to link to that task, or share a URL ending in ?task={{ project.key }}-42 to deep-link it.
  • Filters — Narrow the board or lists by text, assignee, priority, or label.
--- users | Members & Sharing
  • Personal project — A private project is created for you automatically.
  • Shared projects — Create more projects and invite members as Admin or Member.
  • Groups — Link a project to groups to give every group member access.
--- settings | Project Settings
  • General — Admins can rename the project, edit its description and key, and choose how long done tasks stay on the board.
  • Columns — Add, rename, recolor, and reorder board columns.
  • Labels — Manage the project's shared label palette.
  • Danger zone — Archive a project to make it read-only, or delete it for good.
--- code | API Access
  • Base URL: /api/v1/projects
  • Authentication: Use your session cookie or API token.
  • Documentation: Full API docs are available at /schema/swagger-ui/.
