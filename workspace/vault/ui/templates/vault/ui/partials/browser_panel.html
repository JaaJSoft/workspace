{% comment %} What a row is, without opening what it keeps. The login is already in the clear - the listing opened it - so it is shown. The password is not: the field is drawn from `panelCarries`, which reads the field ids the listing collected, rather than from a value. The row of dots is a mask over nothing until the user asks to see it with the reveal button, which decrypts on demand through `toggleReveal`. The plaintext it produces leaves component state the moment the panel closes, another entry is opened, or the vault locks - never on a timer, because it is on screen rather than on the clipboard, and one click undoes it. Every button is gated on `panelHasAction`, which is the endpoint's answer for this row and not a rule written here. {% endcomment %}
