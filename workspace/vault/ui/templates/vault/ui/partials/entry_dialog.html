{% comment %} Creating and editing share one dialog, because they write the same record: a signed entry carries every field on every write, so an edit is a create over an existing uuid. The inputs come from the type's own schema, rendered by the server from the Python registry - adding a type stays one class, with no form to write. autocomplete and spellcheck are off on every content field: a password manager whose fields end up in the browser's own form history, or sent to a spell-checking service, has given away what it exists to keep. {% endcomment %}
