About your vault

Everything is encrypted here

Names, passwords and notes are sealed in this page before anything is sent. The server stores ciphertext it cannot read, and every record carries a signature from your account that it cannot forge.

Your master password cannot be reset

It never leaves this page, so nobody - not an administrator, not the server - can recover it or the vaults it opens. Your recovery key is the only other way in: keep it somewhere you would still have if you lost this device.

The vault locks itself

After a few idle minutes the keys are dropped from memory and the screen empties. The delay is yours to set, in Preferences, beside the countdown in the sidebar.
