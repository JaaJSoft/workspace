{% translate "Everything is encrypted here" %}

{% blocktranslate trimmed %} Names, passwords and notes are sealed in this page before anything is sent. The server stores ciphertext it cannot read, and every record carries a signature from your account that it cannot forge. {% endblocktranslate %}

{% translate "Your master password cannot be reset" %}

{% blocktranslate trimmed %} It never leaves this page, so nobody - not an administrator, not the server - can recover it or the vaults it opens. Your recovery key is not a way around it but the other half of the lock: unlocking takes both, so on a device that does not remember the key, losing either one locks you out for good. Keep the key somewhere you would still have if you lost this device. {% endblocktranslate %}

{% translate "The vault locks itself" %}

{% blocktranslate trimmed %} After a few idle minutes the keys are dropped from memory and the screen empties. The delay is yours to set, in Preferences, beside the countdown in the sidebar. {% endblocktranslate %}
